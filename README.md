# DMCO StepDodgeOnly

## Description  
This patch forces DMCO to use stepdodge only, it will not allow the player to transition from a dodge into another dodge.

## Installation

1. Install exactly as you would any mod, make sure it overwrites DMCO and DMCO dodge framework
